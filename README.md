# 🔔 notify-glance

**윈도우 알림 · 카카오톡 · 디스코드 · 메일 · 스팀 알림을 한곳에 모아 다시 보는 Windows 위젯**

알림은 왔다가 금방 사라지죠. notify-glance 는 그 알림들을 **바탕화면 구석 위젯에 차곡차곡** 모아 둬요.
놓친 알림을 한눈에 보고, **마우스를 올리면 대화를 이어서** 보고, **누르면 그 앱의 그 대화로** 바로 가요.
기록은 **내 PC 에만 암호화해서** 저장돼요.

## 📸 둘러보기

카톡 · 디스코드 · 메일 · 스팀 · 윈도우 알림이 **사람 · 방마다 카드 하나**로 모여요.
카드엔 누가 · 어디서(색 꼬리표) · 내용 · 안 읽은 수가 보여요. 위쪽 **칩**을 누르면 그 출처만 봐요.

## ⬇️ 설치하기

1. 오른쪽 **Releases** 에서 가장 위(Latest) 버전을 열어요.
2. **`NotifyGlance_버전_x64-setup.exe`** 하나만 받아서 실행해요. (`latest.json` · `.sig` 는 자동 업데이트용이라 안 받아도 돼요.)
3. 설치가 끝나면 위젯이 뜨고, 처음엔 **처음 설정** 안내가 열려요. 쓰는 법은 언제든 **설정 → 사용법**에서 볼 수 있어요.

> **"Windows의 PC 보호" 파란 창이 뜨면?**
> 널리 알려지지 않은 개인 프로그램이라 윈도우가 한 번 확인하는 창이에요. **추가 정보 → 실행** 을 누르면 설치돼요.

- 관리자 권한 없이 **내 계정에만** 설치돼요 · Windows 10 / 11 (64비트)
- 처음 설치하면 **윈도우를 켤 때 같이 켜져요** (설정 → 일반에서 끄기)
- 지우려면: 윈도우 **설정 → 앱 → 설치된 앱 → NotifyGlance → 제거**. 기록 · 설정 폴더는 남아서 다시 설치하면 이어져요.

## 🔌 알림 받을 곳 준비

| 출처 | 준비 |
|---|---|
| **윈도우 알림** | 없음. 윈도우 알림 센터에 뜨는 건 다 와요 |
| **카카오톡** | 카톡 알림은 윈도우 알림이 아니라서 **Windhawk** 모드가 필요해요 (아래) |
| **디스코드** | 그냥 써도 윈도우 알림으로 와요. **연동하면** 채널 · 서버 이름, 이어지는 대화, 사진 미리보기까지 (선택) |
| **메일** | Gmail · 네이버: 메일 주소 + **앱 비밀번호** (설정 → 메일 계정에서 차례로 안내, 서버 연결 → 로그인 → 메일 가져오기가 단계마다 보이고 막히면 이유가 나와요) |
| **스팀** | 없음. 깔려 있으면 저절로 (게임 화면 안에만 뜨는 메시지는 못 받아요) |

### 💬 카카오톡 알림 받기 (한 번만, 5분쯤)
1. **[Windhawk](https://windhawk.net)** 설치 (윈도우 프로그램을 고쳐 쓰는 무료 도구)
2. Windhawk 오른쪽 아래 **[새 모드 만들기]**
3. 편집 칸 글을 모두 지우고, notify-glance **처음 설정 3단계(또는 설정 → 알림 받을 곳)의 [모드 코드 복사]** 로 복사한 코드를 붙여 넣기
4. 왼쪽 **[모드 컴파일]** → "모드 활성화" 켜기 → **[편집 모드 나가기]**
5. 모드 **[설정]** 탭: **"기록 파일 경로"** 에 notify-glance 의 **[경로 복사]** 로 복사한 경로를 붙여 넣고 **[설정 저장]**
   - "알림을 파일로 기록" · "프로필 사진 저장"은 **켜 두기** (notify-glance 가 읽는 것). "프로필 저장 폴더"는 비워 두기
   - "알림창을 다른 모니터로 이동"은 카톡 알림 창을 **다른 모니터로 옮기는 기능**이에요. 원래 자리가 좋으면 끄기
6. 카톡을 껐다 켜고 메시지를 하나 받으면 "준비됨"

## 🔄 자동 업데이트
켤 때와 하루 한 번 새 버전을 확인해요.
- 위젯 **⋯ 버튼에 노란 점** · ⋯ 메뉴 맨 위 · 트레이 메뉴 맨 위 · 구석 알림 창(한 번)으로 알려 줘요.
- 누르면 받아서 설치하고 다시 켜져요. **누르기 전에는 아무것도 바뀌지 않아요.**
- 모든 업데이트 파일엔 **디지털 서명**이 있어서, 서명이 맞는 파일만 설치해요.

## 💾 기록 · 설정은 어디에?
- 위치: `%USERPROFILE%\.notifyglance\` · 기록은 **암호화**돼 있고 열쇠는 윈도우 자격 증명 관리자에만 있어요 (파일만 가져가면 못 읽어요).
- 보관 기간 · 휴지통 비우기 · **설정 백업** · **기록 내보내기(.txt · .csv)** 는 설정 → 기록 · 백업.

## 🔒 개인정보
- 알림 기록은 **내 PC 에만, 암호화해서** 저장해요. 알림 내용을 인터넷으로 보내지 않아요.
- 인터넷은 이것들에만 써요: **메일 서버**(내 메일 받기) · **메일 속 사진**(메일 팝업을 열 때, 그 사진이 있는 곳에서 받아 와요. Gmail · 네이버 웹에서 메일을 열 때와 같아요) · **디스코드**(연동했을 때 · 프로필 사진) · **스팀 이미지 서버**(도전과제 아이콘 · 친구 사진) · **새 버전 확인**(GitHub) · 직접 보내는 **문의하기**.
- 메일 · 디스코드 비밀번호는 **윈도우 자격 증명 관리자에만** 저장해요.

## 💌 문의 · 버그 제보
앱 안 **설정 → 문의하기**(트레이 메뉴에도)에서 바로 보내요. 보내지는 것: 적은 글 · 종류 · 연락처(적었다면) · 앱 · 윈도우 버전. 기록 파일은 체크했을 때만, 메일 주소 · 인터넷 주소는 가려서.

## ❓ 자주 묻는 질문
**카톡 알림이 안 와요.**
설정 → 알림 받을 곳(또는 설정 → 정보 → 처음 설정 안내 [다시 보기] → 3단계)에서 "준비됨"인지 보세요. Windhawk 모드의 "기록 파일 경로"가 notify-glance 가 알려 준 경로인지, 코드를 바꾼 뒤 **[모드 컴파일]** 을 했는지 확인해 주세요.

**스팀 친구 메시지가 안 와요.**
게임 화면 안에만 뜨는 메시지는 바탕화면 창이 없어서 받을 수 없어요.

**메일 비밀번호가 틀렸대요.**
평소 로그인 비밀번호가 아니라 **앱 비밀번호**가 필요해요 (Gmail: Google 계정 → 앱 비밀번호 / 네이버: 2단계 인증 → 애플리케이션 비밀번호).

**위젯이 안 보여요.**
작업 표시줄 오른쪽 아래 **트레이 아이콘**을 누르면 보이기 / 숨기기예요.
