# notify-glance

**윈도우 알림 · 카카오톡 · 디스코드 · 메일(Gmail · 네이버) · 스팀 알림을 한 곳에 모아 다시 보는 Windows 위젯**

놓친 알림을 위젯에서 한눈에 보고, 마우스를 올리면 대화를 이어서 보고, 누르면 그 앱의 그 대화로 바로 가요.

## 받기

[Releases](https://github.com/dubooooooooo/notify-glance-releases/releases/latest) 에서 `NotifyGlance_x.y.z_x64-setup.exe` 를 받아 실행하세요.

- 서명이 없는 프로그램이라 "Windows의 PC 보호" 창이 뜰 수 있어요 → [추가 정보] → [실행]
- 처음 켜면 "시작하기" 안내가 위젯 놓기 · 메일 연결 · 카카오톡 · 디스코드 준비를 차례로 도와줘요
- 새 버전이 나오면 프로그램이 알려 주고, 누르면 받아서 설치해요 (자동 업데이트)

## 개인정보

- 알림 기록은 **내 PC 에만** 암호화해서 저장돼요
- 알림 내용은 인터넷으로 보내지 않아요 (메일은 그 메일함하고만 이야기해요)
- 메일 · 디스코드 비밀번호는 Windows 자격 증명 관리자에만 저장돼요

이 저장소는 설치 파일과 자동 업데이트 정보만 담는 배포용 저장소예요.
